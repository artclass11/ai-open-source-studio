# Privacy and Responsible Use

This studio aims to publish tools that can run locally and minimize data collection.

- Projects must not include analytics, tracking pixels, hidden network calls, or bundled credentials.
- Examples and fixtures must use synthetic data only.
- Projects should expose clear boundaries when they handle text that may contain personal or confidential information.
- Redaction is heuristic and is not a guarantee of anonymization. Review output before sharing sensitive material.
- Users must comply with applicable privacy, copyright, consumer-protection, employment, accessibility, and sector-specific requirements.
- Do not use these projects to make high-impact decisions about people without appropriate human review, notice, lawful basis, and applicable safeguards.
